# Suryansh Kala & Sanskriti Foundation

A premium Indian cultural events platform celebrating classical music, dance, theatre, folk arts, and the rich heritage of India. Built as a KIIT Explore Web Designing Project using HTML, CSS, and JavaScript.

## Overview

This project is a visually rich, responsive event management website designed to promote Indian culture and artistic traditions. It allows users to explore upcoming events, browse cultural categories, view detailed event information, and register for their preferred programs.

## Features

- Modern, responsive homepage and multi-page website
- Upcoming events section with cards and event data
- Event search and category filters
- Detailed event information pages
- Registration form with client-side validation
- Successful submission confirmation and local storage support
- Dark/light mode toggle
- Countdown timer for upcoming events
- Premium Indian cultural color palette and aesthetic styling

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Local Storage for registration persistence

## Project Structure

- `index.html` — homepage and landing experience
- `events.html` — searchable and filterable event listing
- `event-details.html` — event details and registration form
- `about.html` — foundation overview and mission
- `raaga-rangaa.html` — music tradition page
- `naatya-rangaa.html` — dance tradition page
- `naataka-rangaa.html` — theatre page
- `vaadhya-rangaa.html` — instruments page
- `naattu-rangaa.html` — folk culture page
- `styles.css` — unified styling and responsiveness
- `script.js` — dynamic content, validation, filtering, theme toggle, and countdown
- `images/` — local design and cultural assets

## Run Locally

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
