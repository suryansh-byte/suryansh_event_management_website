# Suryansh Kala & Sanskriti Foundation

A premium static website concept for celebrating Indian classical arts, music, dance, theatre and cultural heritage.

## Features

- Responsive multi-page layout with a premium Indian cultural aesthetic
- Home, events, category pages, about, and registration flow
- Event search and category filtering
- Event detail pages with registration form
- Local Storage support for registration data
- Dark and light mode toggle
- Countdown for upcoming events
- Newsletter and accessibility-friendly layout

## Files

- `index.html` — Homepage
- `events.html` — Event listing and filters
- `event-details.html` — Event details and registration form
- `about.html` — About the foundation
- `raaga-rangaa.html`, `naatya-rangaa.html`, `naataka-rangaa.html`, `vaadhya-rangaa.html`, `naattu-rangaa.html` — Category pages
- `styles.css` — Shared styling
- `script.js` — Interactions and data handling

## How to run locally

Open `index.html` directly in a browser, or run a local static server from the project folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
